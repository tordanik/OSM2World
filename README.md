**OSM2World** is an Open Source converter that creates three-dimensional models of the world in various formats from OpenStreetMap data. Visit the **[osm2world.org project website](https://osm2world.org/)** for documentation, downloads, screenshots and contact information and make sure to try the **[interactive demo](https://osm2world.org/demo/)**!

# Features

OSM2World can export 3D models as glTF/glb, OBJ and POV-Ray files, generate 3D Tiles, and render images with OpenGL.

You can use it in several ways:

- as a command line tool
- with the graphical viewer included in the desktop application
- as a Java library through Maven/Gradle (see the [JVM library documentation](https://osm2world.org/docs/library-jvm/))
- in a web browser as a JS module (see the [web library documentation](https://osm2world.org/docs/library-web/)).

# Download

Pre-built releases are available on the [download page](https://osm2world.org/download/).

OSM2World's textures, 3D models and visual configuration live in a separate repository: [OSM2World-default-style](https://github.com/tordanik/OSM2World-default-style).
It is included in the pre-built releases, but needs to be downloaded separately if you clone the source code.
